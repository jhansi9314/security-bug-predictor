Built a desktop GUI tool using Python and Tkinter that performs multi-layer static security analysis on source code using regex-based pattern detection, taint analysis, and a trained ML ensemble (Random Forest + Gradient Boosting). Supports 8 languages (Python, JavaScript, Java, C/C++, PHP, Go, Rust), detects 30+ vulnerability types including SQL Injection, XSS, Command Injection, and Buffer Overflow, with CWE mapping, remediation guidance, Semgrep integration, and SQLite-based scan history logging.
